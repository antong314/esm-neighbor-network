Q&A

Put events on your own calendar

How can I add an event to my own calendar? Can I get reminders?

If you'd like an event to appear in your own Google calendar, click into the event and select copy to my calendar. Once it's on your calendar, add notifications as you wish.

Alternatively, if you use Google Calendar, subscribe to the ESM calendar so it appears as one of your calendars: click the + Google Calendar button at the bottom of the calendar view. Note that you'll only receive notifications for these events if the creator of the event set up notifications.

Posting

Add an event to the ESM calendar

To put an event on the ESM calendar, simply include ecovillasanmateocr@gmail.com as a guest in your calendar event. When you send the event it will be automatically accepted onto the ESM calendar for everyone to see.

Guidelines for this shared resource

  • Post events that are open to all members of the community.
  • If you add it, remove or update it as needed. Don't leave events that are no longer valid. When deleting from your own calendar, choose "Send notification to guests" so the ESM calendar removes it too.
  • Include the time zone. Google Calendar adjusts the time automatically for people in other zones.
  • For virtual meetings, put the Zoom or other meeting link in the Location field, ideally when the meeting is created.
  • Be clear and concise in the title, with the main audience or subject early (e.g. "Book Club: Sacred Economics"). Use the description for context.
  • Reserve "ESM" in the title for official meetings provided by the company. Events offered by neighbors should avoid using ESM, for consistency and clarity.
In-person gatherings

Reserving a common area

For in-person gatherings that happen at Ecovilla San Mateo, use the Rio community app to create the event. This lets everyone currently living in the community (or nearby) understand when common areas will be in use by a specific group, and find events they may want to attend.

A reservation communicates intended use — time, place, purpose — and helps avoid overlap. It does not create exclusive or private control of the space: common areas remain accessible to the community. See the Common Area Usage Guidelines.
